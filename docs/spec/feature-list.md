# 功能列表（阶段 3 规格，待用户审阅）

状态：已批准，2026-10-13。

**用户已于 2026-10-13 批准，按文中的建议执行。** 用户同时给出了一句定位，作为今后取舍的总原则：
参照软件好用，是因为它只处理绘画的问题，不处理其他美术方面的问题，所以能兼顾绘画上的专业和好上手。
新软件照此办理：只做绘画。任何"顺便也能做"的功能，默认不做。

## 怎么读这份表

- **研究对象**：官方 PaintTool SAI Ver.2 64 位 2026.07.02b，出厂设置。下文称"参照软件"。
- **本表描述的是行为**，全部用我们自己的话写。新软件不使用参照软件的名称、图标、界面文案、笔刷位图和文件格式。
- **证据等级**：
  - `测`：用自写工具实测到的数值。来源 `analysis/stage1/baseline-results.md`。
  - `看`：走查时直接在界面上观察到。来源 `analysis/stage1/ui-walk.md`。
  - `文`：只在官网公开的更新历史或菜单名称里见到，没有实测过行为。来源 `analysis/stage1/public-docs-notes.md`。标 `文` 的行，"用户可见行为"一栏是按常识写的预期，实现前要先确认。
- **"为什么舒服"** 对应 `docs/hypotheses.md` 里的假设编号。用户已说明看重的是"用着容易、结构简单"，所以 H5、H6、H7、H9 相关的行权重最高。
- **优先级**：`MVP` 第一个可用版本；`P1` 紧随其后；`P2` 之后再说；`不做` 明确排除。
- **难度**按单人开发估计。
- 所有实测都是合成笔输入、240 Hz 屏、单次会话的结果；真实数位板和主观手感没有验证过（用户决定不做）。所以验收一律写成"与参照软件的实测行为一致"，不写"更舒服"。
